# 1.6.16

- Feature: the **Cars** tab is now live for everyone — it was previously QA-only and is now shown in production instead of QA
- Fix: the app tour's Messages/Directory highlight bubbles were sized against a hardcoded 3-tab bottom nav, so they rendered at the wrong width and position now that a 4th tab (Cars) can be present in production
- Fix: the Cars tab rendered a blank screen in production — the bottom-nav button's visibility was flipped to production in this release, but the screen content itself was left gated behind the old QA-only check, so tapping the (now-visible) tab mounted no navigator at all
- Fix: push-notification / deep-link routing into a vehicle-inquiry chat (`openVehicleInquiryConversation`) still bailed out in production under the old QA-only guard, which would have silently dropped Cars notification taps now that the feature is live for everyone

# Detailed Changes

### Bottom navigation (`lib/main_scaffold.dart`)

- `_buildBottomNavigationBar`: the Cars tab's visibility condition flipped from `_isQAEnvironment` to `!_isQAEnvironment` — it now appears in production builds and is hidden in QA (previously the reverse)
- `build`: the `CarsVehiclesScreen` offstage navigator (index 4) had the same condition flipped, from `_isQAEnvironment` to `!_isQAEnvironment`, so the tab actually has content to show now that its button is visible in production
- `openVehicleInquiryConversation`: guard flipped from `if (!_isQAEnvironment) return;` to `if (_isQAEnvironment) return;` so the QA-only early-return doesn't swallow production vehicle-inquiry deep links

### App tour (`lib/main_scaffold.dart`)

- `_buildTourSteps`: `numItems` is no longer a hardcoded `3` — it now mirrors the real tab count built in `_buildBottomNavigationBar` (`_isQAEnvironment ? 3 : 4`), so `AppTourService.navItemRect` divides the nav bar width by the correct number of tabs
- The Directory step's anchor was computed as `numItems - 1` (i.e. "the last tab"), which broke once Cars could sit after it as a 4th tab. It's now hardcoded to index `2`, its actual fixed position (Home, Messages, Directory, [Cars])
- Net effect: on production builds (4 tabs) the Messages and Directory tour bubbles now highlight the correct nav items at the correct width instead of being sized for a 3-tab bar
