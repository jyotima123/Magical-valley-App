# 1.7.2

- Feature: new "Seller" filter on the Cars filter sheet — Dealer or Private Seller (either or both); with neither selected, everything shows
- Feature: vehicle detail now shows the dealership's own name for feed inventory (e.g. the LiftKit dealer) instead of the integration label "LiftKit"
- Feature: the Cars list now shows vehicles without pictures after the ones that have pictures, whatever sort is selected
- Change: revamped the Magic Market initial screen
- Change: Market's "My Listings" moved from a left-hand drawer into a menu at the top right, next to the Add button

# Detailed Changes

### Cars filters (`lib/modules/cars/vehicle_search_filters.dart`, `lib/modules/cars/cars_search_screen.dart`)

- `VehicleSearchFilters` gains `sellerTypes` (`Set<String>` of `Dealer` / `Private Seller`), with the option list and labels as static constants
- `matches()` classifies a listing as Dealer when `isFromDealerFeed` (LiftKit and every ingested feed) and Private Seller otherwise (community listings); an empty set matches both
- Counts toward `activeCount`, so it feeds the filter badge and the "N filters applied" bar, and is cleared by "Reset all" / "Clear all"
- New `_buildSellerTypeSection()` at the top of the filter sheet, reusing `_ChipGroup`; wired through `initState`, `_buildFilters()` and `_resetAll()`

### Vehicle detail (`lib/modules/cars/vehicle_detail_screen.dart`)

- `_loadSellerName()` now selects `display_name, organizations(name)` from `dealer_sources` and prefers the linked organization's name, falling back to `display_name` when no organization is linked
- Requires `dealer_sources.organization_id` to be set for the dealership to show; the seeded `liftkit` row has it `NULL`, so until it is linked (or `display_name` is edited) the row still reads "LiftKit":

  ```sql
  UPDATE dealer_sources SET organization_id = '<organizations.id>' WHERE source = 'liftkit';
  ```

### Cars list (`lib/modules/cars/vehicles_screen.dart`)

- `_recomputeMatches()` does a stable partition right after `_filters.sort()`: listings with at least one image first, then those with none, preserving the chosen sort within each group. The existing "own listings first" partition runs after it, so a seller's own cars still lead the list

### Market (`lib/modules/market/market_screen.dart`)

- Revamped the Magic Market initial screen

- Removed the left `leading` menu button and the `Drawer`
- Added a `PopupMenuButton` after the Add button, styled like `ChatMenuButton` (`Icons.menu`, 12px rounded shape), with a single "My Listings" item that opens `MyListingsScreen`
