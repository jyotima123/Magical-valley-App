# 1.6.8

- Channel list mute icon is now always grey regardless of mute state, with a smaller size for a cleaner look
- Channel list trailing redesigned WhatsApp-style: timestamp at the top-right, mute icon and unread dot at the bottom-right
- Organization business profile: bio, website, phone numbers, and addresses (WhatsApp Business-style) displayed on the Channel Profile screen
- `ManagementButton` gains optional `showChevron` and `subtitleMaxLines` parameters
- Migration 065: `organizations` table gains `bio` and `website_url` columns; new `organization_phone_numbers` and `organization_addresses` tables; `organizations_overview` view updated to aggregate all new fields as JSONB
- Channel Profile screen typography unified to Poppins across all text elements with a consistent size/weight scale
- Bio field renders newlines correctly instead of showing literal `\n`
- Website URL hides `http(s)://` prefix in the display label; full URL still used when opening the browser
- Website row truncates with ellipsis instead of wrapping to multiple lines
- Messaging icon unified to `Icons.forum` across Channel Profile and All Channels list
- All Channels list redesigned from shadow cards to a compact divider list matching the Channels tab style
- Direct Messages screen: white background, Poppins AppBar title, and unified dividers matching all other screens
- Added new fields to channel management edit menu

# Detailed Changes

### Channel list mute icon (`channels_list.dart`)

The bell icon in the channel list title row is now always rendered in grey (`Colors.grey.shade400`) and at a slightly smaller size (14 px, down from 16 px). Previously the icon was green when notifications were enabled and grey only when muted, which drew unnecessary visual weight. The icon itself still switches between `Icons.notifications` and `Icons.notifications_off` to reflect the mute state, but the colour no longer changes.

### WhatsApp-style channel list trailing (`channels_list.dart`)

The trailing widget on each channel tile was refactored from a `Row` (timestamp and unread dot side-by-side) to a `Column` that mimics WhatsApp's conversation list layout:

- **Top**: last-message timestamp, right-aligned.
- **Bottom**: unread indicator dot (10 px circle) and mute icon side-by-side, right-aligned.

The mute icon was moved out of the `title` Row so the channel name takes the full available width.

### Channel Profile screen typography (`organization_profile_screen.dart`)

All text in the Channel Profile screen now uses Poppins consistently. Previously, inline `TextStyle(...)` blocks without an explicit `fontFamily` fell back to the system font, creating a mixed-font appearance. Every text element now references an `AppTheme` style or specifies `fontFamily: 'Poppins'` directly. The size/weight scale is:

| Role | Size | Weight |
|---|---|---|
| Org name | 22 | bold |
| AppBar title, action labels | 16 | w600 |
| Bio body | 14 | normal |
| Follower count, badges, captions | 12 | normal / w500 |

### Organization business profile (`organization_profile_screen.dart`, `organization_model.dart`)

The Channel Profile screen now shows a **Business Info** card between the header and the actions section, rendered only when at least one field is populated. Fields:

- **Bio** — plain text paragraph with an info icon; no chevron. Literal `\n` escape sequences stored in the database are converted to real newlines before rendering.
- **Website** — tappable via `url_launcher` (`LaunchMode.externalApplication`); bare hostnames are prefixed with `https://` automatically. The `http(s)://` scheme is stripped from the displayed label. Long URLs truncate with an ellipsis rather than wrapping.
- **Phone numbers** — one `ManagementButton` per entry; tapping opens the system dialer (`tel:` URI). The optional `label` (e.g. "Main", "Support") is used as the row title.
- **Addresses** — one `ManagementButton` per entry; tapping opens Google Maps with the formatted address as a query. Parts are joined from `street`, `city`, `state`, `country`, `postal_code`.

The `Organization` model was extended with `bio`, `websiteUrl`, `phoneNumbers` (`List<OrgPhoneNumber>`), and `addresses` (`List<OrgAddress>`). Both helper classes parse from the JSONB arrays returned by `organizations_overview`. `toDatabaseJson` and `toCreateJson` now include `bio` and `website_url`.

### `ManagementButton` (`management_button.dart`)

Added `showChevron` (default `true`). When `false`, the trailing `chevron_right` icon is omitted, making the button suitable for contact-info rows where tapping performs an action (dial, open URL) rather than navigating to a new screen.

Added `subtitleMaxLines` (optional `int`). When set, the subtitle text clips with an ellipsis instead of wrapping — used on the website row to keep it single-line.

### Messaging icon (`organization_profile_screen.dart`, `categories_grid_screen.dart`)

The messaging action icon is now `Icons.forum` in both the Channel Profile actions row and the All Channels list message button, replacing the previous `Icons.mail_outline`. This makes the icon consistent wherever the "Message" action appears.

### All Channels list layout (`categories_grid_screen.dart`)

The organisation cards (white containers with rounded corners, shadows, and 12 px bottom margins) were replaced with a compact flat list identical in feel to the Channels tab:

- `ListView.builder` → `ListView.separated` with `Divider(height: 1, color: AppTheme.dividerBackground)`
- No per-item padding or outer margin — standard `EdgeInsets.symmetric(horizontal: 16, vertical: 10)` inside each row
- Logo shrunk from 60 px to `CircleAvatar(radius: 20)` matching the channel list avatar size
- Name/subtitle use `AppTheme.chatTitle` / `AppTheme.chatTimestamp` (Poppins, same as every other list)
- Follow button replaced by a compact `TextButton` pill with no fixed-size container
- Message button replaced by an inline `IconButton(Icons.forum)` — no text label, no border

### Direct Messages screen (`direct_messages_screen.dart`)

Visual consistency fixes to match the Channels and Explore tabs:

- Scaffold background changed from `AppTheme.cardGreyBackground` (grey) to `Colors.white`
- AppBar title now uses `AppTheme.chatTitle` (Poppins 16 w600) and `elevation: 0`
- Conversation list separators changed from `Divider(thickness: 0.5, color: dividerBackground.withOpacity(0.5))` to the canonical `Divider(height: 1, color: AppTheme.dividerBackground)`
- Selected-conversation highlight no longer has a drop shadow — just a flat `AppTheme.cardGreyBackground` fill
- `_ChatScreen` AppBar (narrow-screen chat view) also updated to `AppTheme.chatTitle` style with `elevation: 0` and unified `foregroundColor: AppTheme.black`

### Migration 065: organization business profile (`migrations/065_organization_business_profile.sql`)

- `ALTER TABLE organizations ADD COLUMN bio TEXT, ADD COLUMN website_url TEXT`
- New table `organization_phone_numbers`: `id`, `organization_id`, `label`, `phone_number`, `display_order`
- New table `organization_addresses`: `id`, `organization_id`, `label`, `street`, `city`, `state`, `country`, `postal_code`, `display_order`
- Both new tables have RLS: `SELECT` for any authenticated user; `ALL` for the org's own admins and superadmins
- `organizations_overview` view recreated to include `bio`, `website_url`, and pre-aggregated `phone_numbers` / `addresses` JSONB arrays — no client-side JOINs required
