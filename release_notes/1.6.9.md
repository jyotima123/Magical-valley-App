# Detailed Changes

### Migration 066: GPS + photos (`migrations/066_organization_gps_and_photos.sql`)

- `ALTER TABLE organization_addresses ADD COLUMN latitude DOUBLE PRECISION, ADD COLUMN longitude DOUBLE PRECISION, ADD COLUMN maps_url TEXT`
- New table `organization_photos`: `id`, `organization_id`, `photo_url`, `caption`, `display_order`, `created_at`
- RLS on `organization_photos`: `SELECT` for authenticated users; `ALL` for org admins and superadmins
- `organizations_overview` recreated: addresses JSONB now carries `latitude`, `longitude`, `maps_url`; new `photos` JSONB array aggregated by `display_order`
- ⚠️ Storage bucket `organization-photos` (public) must be created in the Supabase dashboard

### Migration 067: org-level maps URL (`migrations/067_organization_maps_url.sql`)

- `ALTER TABLE organizations ADD COLUMN maps_url TEXT` — single Google Maps / Apple Maps share link for the whole place
- `organizations_overview` recreated to expose the new column

### Organization model (`organization_model.dart`)

- `OrgAddress` gains `latitude`, `longitude`, `mapsUrl`, `hasGps` getter, and `mapsLaunchUrl` computed property (prefers GPS pin → `mapsUrl` → formatted-address search fallback)
- New `OrgPhoto` class with `id`, `photoUrl`, `caption`
- `Organization` gains `mapsUrl` and `photos: List<OrgPhoto>`
- All new fields wired into `fromJson`, `copyWith`, `toDatabaseJson`, `toCreateJson`
- Local cache serialization updated accordingly

### Organization profile screen (`organization_profile_screen.dart`)

- **Photo gallery** — horizontal scrollable strip (130 px tall, 120 px cards) shown above the Business Info card when photos exist; tapping opens `ImageCarouselScreen` at the correct index
- **Location button** — `ManagementButton` with a red map-pin icon and subtitle "Open in Google Maps"; shown in the Business Info card when `org.mapsUrl` is set; tapping launches the URL directly
- **Address tap** — now uses `address.mapsLaunchUrl` (GPS pin when available, otherwise `mapsUrl`, otherwise formatted-address query)
- `_hasBusinessInfo` guard updated to include `mapsUrl`

### Edit Channel screen (`organizations_management_screen.dart`)

- **Google Maps Link field** — `TextFormField` with `location_on` prefix icon; paste a `goo.gl` share link; saves to `organizations.maps_url`; same border/font/label style as the other fields
- **Photos section** — horizontal scrollable grid of existing photos with × delete buttons (confirmation dialog → delete from `organization_photos` table); "Add" button triggers `pickMultiImage` → upload via `SupabaseApiService.uploadGenericFile` → insert into `organization_photos`; tapping any thumbnail opens `ImageCarouselScreen`
- **`?` help button** — `IconButton(Icons.help_outline)` placed to the right of the profile picture; opens `EditChannelOnboarding` as a full-screen route
