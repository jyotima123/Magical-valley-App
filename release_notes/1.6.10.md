# Detailed Changes

### Manage panel (`main_scaffold.dart`, `chat_app_bar.dart`, `manage_tab_screen.dart`)

- `ManageTabScreen` extracted to `lib/modules/admin/manage_tab_screen.dart` as a standalone `StatelessWidget` with a standard `AppBar` and back navigation
- Manage bottom navigation tab removed for all admin users — the three management screens (Users, Channels, Categories) are now reached via the hamburger menu `→ Manage`
- `ChatMenuButton` (in `chat_app_bar.dart`) gains a **Manage** entry in the admin section of the popup menu, visible to `admin` and `superadmin` roles
- `_getActualTabIndex` / `_getVisualTabIndex` simplified: all users now share the same 3-tab layout (Home, Messages, Directory)
- App tour `numItems` updated from `isAdmin ? 4 : 3` to a constant `3`

### Bug fixes

- **Search button location** — search icon in the Messages tab restored to its correct position in the app bar
- **Direct Messages profile pictures** — fixed user avatars not loading on the Direct Messages conversation list screen

### Admin management (`organizations_management_screen.dart`, `migrations/068_fix_admin_promotion_authorization.sql`)

- **Infinite loading after admin actions** — `showDialog` (loading spinner) pushes onto the root navigator by default, but `Navigator.pop(context)` from inside `ManageAdminsSheet` (shown via `showModalBottomSheet`, which uses a local navigator) was closing the sheet instead of the dialog. Fixed by using `Navigator.of(context, rootNavigator: true).pop()`. Added `mounted` guards before all UI operations after `await`. Added `try/catch` to `_removeAdminFromOrganization` which previously had none.
- **Admin promotion authorization** (`promote_user_to_admin`, `remove_admin_from_organization`) — both Supabase RPC functions were `SECURITY DEFINER` with no caller authorization: any authenticated user could call them. Fixed in migration 068: functions now identify the caller via `auth.uid()` and enforce role-based rules — regular users are blocked; admins can promote/self-remove only within orgs they manage; superadmins have full access; superadmin accounts cannot be modified from the app.
