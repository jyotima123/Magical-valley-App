# 1.6.1

- Format phone number as +1 (XXX) XXX-XXXX in the OTP verification screen and in the success message after sending the code

# Detailed Changes

### Phone number display formatting

Two places were showing the raw E.164 payload (`+11234567890`) to the user instead of a readable format.

- `sms_otp_verification_screen.dart` — the subtitle "We've sent a 6-digit verification code to …" now passes `widget.phoneNumber` through a `_formatPhone` helper before rendering it.
- `auth_bloc.dart` — the success message emitted after a code is sent (`_onChoosePhoneVerification`) now reads "Text message code sent to +1 (XXX) XXX-XXXX" instead of the raw E.164 string.

Both helpers follow the same rule: if the number matches `+1XXXXXXXXXX` (exactly 12 characters), format as `+1 (XXX) XXX-XXXX`; otherwise fall back to the original string unchanged, so QA numbers typed manually are unaffected.
