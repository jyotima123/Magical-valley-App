# Detailed Changes

### Phone input redesign (production only)

On production, the plain text field for phone number entry has been replaced with a PIN-code-style input. A hidden `TextField` (height 0, digits only, capped at 10 characters) captures keyboard input and auto-focuses on sheet open. The visual layer renders a `+1` prefix chip followed by 10 underline-style digit boxes grouped in `(XXX) XXX-XXXX` format. Each box highlights in the accent color when it is the active position. The payload sent to the API remains unchanged (`+1XXXXXXXXXX` in E.164 format — no spaces or formatting characters).

QA (development flavor) retains the original free-form text field where the full international number must be typed manually.

### Send Code button state

The button is disabled until all 10 digits are filled on production. `disabledBackgroundColor` changed from `accentPrimary.withOpacity(0.4)` (orange tint) to `Colors.grey[300]`.

### Copy changes

- Verification option card: "Verify via SMS" → "Verify via Text Message", subtitle updated to match.
- Bottom sheet subtitle: replaced the "10-digit" phrasing with "We'll send a verification code to your phone."
- Button label: "Send SMS Code" → "Send Code".
- Hint text below digit input: "Tap above to type your phone number".
